# dashboard

React (Vite) command dashboard for authorities (Phase 5). A dark "control room"
web app providing a live 2D venue map with density/risk heatmap, analytics
charts, an AI intervention panel with one-click broadcast actions, a voice
assistant trigger, external-trigger simulation buttons, and a 3D digital twin.

## Subfolders

| Folder | Purpose |
|---|---|
| `src/` | React source (components, hooks, store, API client). |

**Status:** Scaffolding only — no logic implemented yet.
