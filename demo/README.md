# demo

Assets and orchestration for the hackathon pitch demo (Phase 7): demo videos
standing in for live camera feeds, cached mock data, and the run-of-show
scripts that drive the end-to-end presentation.

## Subfolders

| Folder | Purpose |
|---|---|
| `videos/` | Hand-picked demo clips (calm / bottleneck / panic scenarios). |
| `mock_data/` | Cached social sentiment data, zone configs, and pre-generated announcement audio. |

**Status:** Scaffolding only — no logic implemented yet.
