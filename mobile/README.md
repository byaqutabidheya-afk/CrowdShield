# mobile

Citizen-facing companion mobile app (React Native / Expo, Phase 6). Delivers
geofenced, multilingual push alerts, shows the user's location relative to
active risk zones, lets citizens submit incident reports with GPS + photos,
and provides vulnerability-aware safe-route navigation away from high-risk
zones.

## Subfolders

| Folder | Purpose |
|---|---|
| `src/` | React Native source (screens, store, hooks, services, i18n). |

**Status:** Scaffolding only — no logic implemented yet.
