# genai_pipeline

Generative AI layer (Phase 3). Translates numerical risk data from
`risk_engine` into human-actionable intelligence: tactical recommendations,
post-incident summaries, multilingual announcements with text-to-speech audio,
mocked social-media sentiment analysis, and the voice command center
(speech-to-text + intent matching + spoken responses).

## Subfolders

| Folder | Purpose |
|---|---|
| `scripts/` | LLM client abstraction, recommendation engine, incident summaries, translation + TTS, sentiment analysis, voice commands, and the orchestration pipeline. |

**Status:** Scaffolding only — no logic implemented yet.
